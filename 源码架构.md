# Aegisub 源码架构索引

> 用途：给 agent / 开发者快速定位 `./Aegisub` 原版源码（约 766 个 C++ 文件）。粒度 = 文件级 + 一句话职责；**不写行号**（避免过期）。所有内容均基于逐文件实读源码得出，非文件名猜测。
> 路径约定：`src/` = `Aegisub/src/`，`la/` = `Aegisub/libaegisub/`，`lainc/` = `Aegisub/libaegisub/include/libaegisub/`（大部分头文件的真正位置）。同名 `.h` 默认与 `.cpp` 同目录，不重复标注。

## 0. 总览与分层

```
wxWidgets UI 层     src/*.cpp（视图、对话框、命令）——自绘控件 + 事件绑定
      │  agi::Context（模型+控制器聚合体，见 src/context.cpp / include/aegisub/context.h）
      │  cmd::Command 全局注册表（src/command/）——菜单/热键/工具栏共用
      ▼
应用逻辑层         project / subs_controller / audio_controller / video_controller /
                  audio_timing_* / selection_controller / search_replace_engine /
                  subtitle_format / auto4_*（src/）
      ▼
平台无关库 libaegisub（la/）  ASS 模型、配置、热键、信号、dispatch、vfr、charset…
      ▼
第三方             wx / boost / ICU / LuaJIT / FFMS2 / Avisynth / hunspell / fftw / iconv
```

目录速览：

| 目录            | 内容                                                                                                                                                                                                                                                      |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/`          | 主程序（wx UI + 控制器 + provider/player 后端），`command/`（命令域）、`include/`（接口头：audio_player/video_provider/subtitles_provider/hotkey/menu/toolbar/context）、`libresrc/`（打包资源）、`gl/`（glext.h）、`bitmaps/`（图标 16~64 五档）、`osx/` |
| `la/`           | 平台无关库；`include/libaegisub/` 为全部公开头；`windows/ unix/ osx/` 平台实现层                                                                                                                                                                          |
| `automation/`   | 官方 Lua/Moon 脚本（autoload 与 include/aegisub 的 moon 绑定层）                                                                                                                                                                                          |
| `tests/ tools/` | 单元测试；构建辅助（respack.py 打包资源、combine-config.py 合并平台配置）                                                                                                                                                                                 |

四大全局机制（移植时必须重建的核心抽象）：

1. **cmd 命令注册表**：约 270 个命令按域注册进 `static map<string, unique_ptr<Command>>`，与 wx id 解耦；`cmd::call` 内先 Validate 再执行。
2. **agi::signal**（`lainc/signal.h`）：vector<token,fn> + 逆序触发 + Block/Unblock；`DEFINE_SIGNAL_ADDERS` 把私有信号暴露为 `AddXxxListener`。无线程安全。
3. **Options 配置树**（`la/common/option.cpp`）：JSON 树 → 扁平 "A/B/C" 键 + 严格类型 OptionValue；宏 `OPT_GET/OPT_SET/OPT_SUB` 在 `src/options.h`；析构时自动 Flush 写盘。
4. **dispatch**（`la/common/dispatch.cpp`）：asio 线程池 + Main（GUI 桥）/Background/Serial 三队列。

| `la/ass/string_codec.cpp`                  | inline_string_encode：`#`+两位十六进制，必须转义 0x00-0x1F、`#` `,` `:` `\|`（Extradata 用）                                                                                             |

**信号链**：`Commit` → PushState（仅 SubsController 订阅=undo 管理）→ AnnounceCommit（订阅者：AudioKaraoke、AudioTimingControllerDialogue、BaseGrid、DialogStyleManager、DialogTranslation、FrameMain、SubsEditBox、VideoBox、VideoController、VisualToolBase）。

**坑**：分辨率缺省 384x288 且单边 1280/1024 时另一边取 1024/1280（Gabest 逻辑）；Margin[0] 是左；`Row` 是 UI 行号非文件字段；未闭合 `{` 按 VSFilter 当纯文本；Style 名大小写不敏感但需唯一；`\t` 可选参数靠位掩码；AssDialogue 拷贝每次新分配 Id（undo 行匹配不能只靠 Id）；`\clip/\iclip` 按参数个数区分矩形/矢量。

## 11. 配置 JSON 树结构（default_options 语义）

- 树形即层级：`{"Audio":{"Player":{"Name":"…"}}}` → "Audio/Player/Name"。
- 列表项必须单键对象：`[{"int":1},{"int":2}]`；空数组无法推断类型直接报错。
- aegisub-data/*.json 与 `src/libresrc/default_*.json` 必须严格一致（本项目硬约束）。
- 关键热选项：`Audio/Spectrum`、`Audio/Provider/*`、`Video/Provider`、`Provider/Audio/Video` 系列、`Colour/Subtitle/Syntax/*`（语法高亮经 OPT_SUB 热更新）、`Limits/Undo Levels`、`Limits/MRU`、`Tool/Preferences/Page`。
